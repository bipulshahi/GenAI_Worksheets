### Summary: Traditional Programming vs Machine Learning

| Comparison | Traditional Programming          | Machine Learning                 |
| ---------- | -------------------------------- | -------------------------------- |
| **Input**  | Rules (if–else logic)            | Data (examples)                  |

| **Logic**  | Explicit logic written by humans | Implicit logic learned from data |

### Definitions

**Classification**
Predicting discrete categories
*Examples:* PASS/FAIL, Spam/Not Spam, Cat/Dog

**Regression**
Predicting continuous numbers
*Examples:* Marks, Price, Temperature

---

### Relation Between Classification & Regression

Which happens first?

* ⬜ Predict a number, then apply a cutoff
* ⬜ Directly predict PASS or FAIL

**Correct Insight:**
Regression → Threshold → Classification

```
68 marks → PASS if ≥ 50 → PASS
```

## Workshop Module 3: Supervised vs Unsupervised Learning

---

## Part 1: Supervised Learning

> Data has **inputs + correct outputs**

**Definition**

```
SUPERVISED LEARNING
Learning from labeled data (inputs + outputs)

Includes:
• Classification
• Regression
```

---

## Part 2: Unsupervised Learning

> Data has **inputs only**, no correct answers.

### Customer Segmentation (Example)

| Segment                  | Strategy                   |
| ------------------------ | -------------------------- |
| Segment 1 (Top Right)    | __________________________ |
| Segment 2 (Top Left)     | __________________________ |
| Segment 3 (Bottom Left)  | __________________________ |
| Segment 4 (Bottom Right) | __________________________ |

**Definition**

```
UNSUPERVISED LEARNING
Finding hidden structures without labels

Examples:
• Customer Segmentation
• Clustering
• Grouping Images
```

---

## Part 3: Semi-Supervised & Reinforcement Learning

### Semi-Supervised Learning

Small labeled data + large unlabeled data

```
Example:
Doctor labels few X-rays
Model labels the rest
```

---

### Reinforcement Learning

> Learning through **trial and error**

| Action    | Result      |
| --------- | ----------- |
| Good move | Reward (+)  |
| Bad move  | Penalty (–) |

**Key Insight:**
The system generates its **own data**.

## Workshop Module 4: AI vs ML vs DL

### Hierarchy

```
Artificial Intelligence
 └── Machine Learning
      └── Deep Learning
```

---

### Definitions

#### Artificial Intelligence — *The Dream*

* Any system that behaves intelligently
* Rule-based or learning-based

#### Machine Learning — *The Method*

* Learns patterns from data
* No explicit rules

#### Deep Learning — *The Engine*

* Neural networks with many layers
* Learns features automatically
