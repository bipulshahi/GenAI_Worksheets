Definitions 

In Machine Learning, these two types of tasks have specific names: 

* 
**Classification:** predicting discrete or fixed categories or labels.


* 
*Examples:* PASS/FAIL, Spam / Not Spam, Yes / No, Cat/Dog.




* 
**Regression:** predicting continuous numerical values.


* 
*Examples:* marks, house price, temperature, delivery time.





Relation Between Classification and Regression 

In real systems, which usually happens first? 

* [ ] Predict a number, then apply a cutoff 


* [ ] Directly predict PASS or FAIL 



Regression is done first. Classification is obtained by applying a threshold on the regression output. 

* 
**EXAMPLE:** 


* Predicted marks: 68 (**Regression**) 


* Threshold: PASS if marks ≥ 50 (**Thresholding**) 


* Final output: PASS (**Classification**)

# MODULE 3: SUPERVISED VS. UNSUPERVISED LEARNING

Part 1: Recap 

Look back at Task 1 (Pass/Fail) and Task 2 (Marks): In both cases, you were given a dataset that included both the **Inputs/Features** (Hours Studied, Sleep) and the correct **Outputs/Target/Labels** (Outcome/Score).

**SUPERVISED LEARNING:** Type of machine learning where a model is trained on data having both inputs and outputs, to make predictions on new data.

* Classification and Regression are both types of Supervised Learning.

---

Part 3: The Hybrid & The Gamer 

1. Semi-Supervised Learning 

* **The Problem:** Labeling data is expensive. Imagine you have 10,000 chest X-rays, but hiring a doctor to label them costs $100 per image.


* 
**The Solution:** The computer first groups similar X-rays together (Clustering). The doctor then labels just a few examples from each group. The system automatically applies these labels to the rest of the group.



**SEMI-SUPERVISED LEARNING:** Type of machine learning that uses a small amount of labeled data and a large amount of unlabeled data.

* 
*Examples:* Google Photos (you name a face once, it finds it everywhere), Medical Imaging.



2. Reinforcement Learning 

* **The Scenario:** You are training a robot dog. You don't give it data. You just put it in a room.


* If it walks forward → You give it a **Reward** (+10 points / Treat).


* If it hits a wall → You give it a **Penalty** (-10 points / Scolding).




* 
**Question:** After bumping into the wall 50 times, what will the robot eventually learn to do? 


* **Key Insight:** It doesn't wait for human-collected data. It generates its own data through rapid trial and error.



**REINFORCEMENT LEARNING:** Learning by interacting with an environment through "trial and error" to maximize a reward.

* 
*Examples:* Chess engines (AlphaGo), Self-driving cars parking, Training video game bots.

# MODULE 4: AI VS. ML VS. DL

**The Hierarchy of Intelligence** 
AI, ML, and DL are not separate technologies. They are subsets of one another, similar to Russian Nesting Dolls.

1. 
**Artificial Intelligence (The Outer Circle): "The Dream"** 


* The broad umbrella term for any technique that enables computers to mimic human intelligence.


* 
*Definition:* Any computer program that does something "smart".


* 
*Scope:* Includes everything from ChatGPT down to simple if-else rules from the 1980s.


* 
*Key Takeaway:* All Machine Learning is AI, but not all AI is Machine Learning.




2. 
**Machine Learning (The Middle Circle): "The Method"** 


* A subset of AI. A shift from "telling computers what to do" to "teaching computers how to learn".


* 
*Definition:* Algorithms that parse data, learn from it, and apply what they've learned to make decisions.


* 
*The Difference:* Instead of defining a "cat" with 10,000 lines of code, you feed the algorithm 10,000 pictures of cats and it finds the patterns.




3. 
**Deep Learning (The Inner Circle): "The Engine"** 


* A specialized subset of Machine Learning inspired by the human brain.


* 
*Definition:* ML that uses Artificial Neural Networks with many layers.


* *The Difference:*
* 
**Classic ML:** You have to "hand-hold" the model by giving specific features (e.g., Area, Bedrooms for house prices).


* 
**Deep Learning:** It gets features on its own from raw data (e.g., finding edges/shapes in images).
