### **Reflection**

Why can’t this raw data be directly used to train a machine-learning model?

* ML models cannot handle missing values directly
* Different feature scales bias learning
* Categorical text data must be converted to numbers
* Raw data leads to unreliable predictions
**Raw data contains missing values, inconsistent scales, and categorical features, which ML models cannot process directly without preprocessing.**

## **HANDS-ON: PANDAS DATAFRAME & MISSING VALUES**

### **Hands-On Exercise 1: Create a DataFrame**

```python
import pandas as pd

data = {
    "Age": [25, None, 55, 45, 35],
    "Income": [25000, 40000, 30000, None, 45000],
    "City": ["Delhi", "Delhi", "Chennai", "Mumbai", "Delhi"],
```


## **FEATURE SCALING, ENCODING & NEW DATA**

### **Feature Scaling**

```python
from sklearn.preprocessing import StandardScaler

scaler = StandardScaler()
df[["Age", "Income"]] = scaler.fit_transform(df[["Age", "Income"]])
df
```
